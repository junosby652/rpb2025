# Warp 학습 모델 평가

이번 학습은 기존 모델에서 이어 학습한 것이 아니라 seed=42로 새로 시작한 2,048개 에피소드 실험이다. 정확한 설정은 evaluation.json의 training_config에 보존했다.

평가 시드 3000~3019의 동일한 초기 관절 잡음을 각 정책에 적용했다. 학습 중 모델 선택 시드 900~902와 분리했다. 모든 정책을 현재 CPU MuJoCo 버전으로 다시 평가했으므로 과거 문서의 다른 버전 평가값을 그대로 가져오지 않았다.

| 길이 | 정책 | 속도 m/s (평균±표준편차) | 파워 W | 속도 추종 | 넘어짐 | 절대 옆 변위 m |
|---|---|---:|---:|---:|---:|---:|

## 관측 결과

- 12초: 기존 → 이번 best 속도 0.2249 → 0.2326m/s, 속도 추종 0.9156 → 0.9030, 기계적 파워 -3.72%, 절대 옆 변위 0.121 → 0.127m.
- 60초: 기존 → 이번 best 속도 0.1951 → 0.1805m/s, 속도 추종 0.8501 → 0.7836, 기계적 파워 -3.49%, 절대 옆 변위 5.505 → 6.856m.

## 평가 판단

- 12초: 평균 전방 속도는 0.2249 → 0.2326m/s로 목표 0.25m/s에 가까워졌고 기계적 파워는 약 3.72% 줄었다. 다만 속도 추종 점수는 0.9156 → 0.9030으로 낮아져 순간 속도의 안정성이 함께 개선됐다고 볼 수 없다.
- 60초: 평균 전방 속도는 0.1951 → 0.1805m/s로 낮아졌고, 절대 옆 변위는 5.505 → 6.856m로 커졌다. 속도 추종 점수도 0.8501 → 0.7836으로 낮아졌다. 기계적 파워는 약 3.49% 낮았지만 장시간 직진 성능 개선으로 판단하지 않는다.
- 두 정책 모두 12초·60초 각각 20회 평가에서 넘어짐은 없었다. 이번 모델은 평지에서 보행을 유지하지만 직진성을 해결하지 못했다. 기존 모델을 대체할 종합적인 개선이 입증된 결과는 아니다.
- 다음 개선은 몸통 heading/yaw와 옆 위치·속도를 관측하고, 고정 보행 파라미터 위에 방향 피드백을 넣는 방식이 적절하다. 현재 상수 관측·에피소드당 행동 1회 구조는 누적 방향 오차를 학습으로 수정하기 어렵다.

## 영상과 해석 범위

- best와 final의 결정적 행동이 완전히 같아 평가 결과와 영상도 동일하다. 같은 행동의 중복 물리 평가는 재사용했다.
- reference_12s.mp4는 기존 CPU best, best_12s.mp4와 final_12s.mp4는 이번 학습 결과다. 영상 시드는 평가의 첫 시드다. 한 영상은 전체 20개 초기 상태를 대표하지 않는다.
- 영상은 CUDA 학습 중 화면 녹화가 아니라 학습한 정책을 CPU MuJoCo에서 재생한 결과다. 평가는 CPU 전이 성능을 측정하며 Warp 장기 궤적 평가와 구분한다.
- 목표 속도는 0.25m/s다. 빠른 속도만으로 우수하다고 판단하지 않는다. 속도 추종 점수는 높을수록, 넘어짐·몸체 기울기·옆 변위는 낮을수록 좋다.
- 에너지는 절대 기계적 일이며 배터리 소비전력과 다르다. CSV/JSON에 에너지·자세 지표를 포함했다.
- 각 방법의 학습 시드는 하나다. 표준편차는 평가 초기 상태에 따른 변동이며 독립 학습 반복의 불확실성이 아니다. 일반적인 우월성이나 통계적 유의성을 주장하지 않는다.
- 고정 트로트 위상과 역기구학을 이용한 6개 보행 파라미터 학습이며 평지에서만 평가했다. 원본 결과·체크포인트를 덮어쓰지 않았고 PPT는 생성하지 않았다.
